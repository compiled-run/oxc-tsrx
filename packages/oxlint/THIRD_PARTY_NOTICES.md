# Third-party notices

This package delegates ordinary source to the official `oxlint` 1.74.0 npm
package and type-aware work to `oxlint-tsgolint` 0.24.0. Those packages retain
their own license and notice files when installed.

The matching `@oxc-tsrx/native-*` package carries the notices for the linked
Rust/OXC binary distribution. `@oxc-tsrx/runtime` carries its JavaScript
runtime notice.
